# 🏫 미래소프트 2기: 충북청년미래센터 메타버스 프로젝트

충북청년미래센터의 청년 참여 및 정보 제공 극대화를 위한 ZEP 기반 2D 메타버스 구축 프로젝트입니다. 고립·은둔 청년 및 가족돌봄 청년이 대면 접촉 없이도 센터 지원 사업 정보를 쉽게 얻을 수 있도록, 익명성과 게임성을 결합한 '여고추리반' 스타일의 추리·탐색형 공간으로 기획되었습니다.

## 🗓 프로젝트 개요

- **개발 기간:** 2026. 10. (총 4주간 진행)
- **플랫폼:** ZEP (PC 및 모바일 웹 브라우저 기반)
- **주요 목표:** 100인 동시접속 환경 최적화, 퀘스트 클리어에 따른 실물 보상(기프티콘 등) 연동, 센터 정식 오픈

## 🛠 기술 스택

- **Environment:** ZEP Map Editor, Node.js (포맷팅 및 린팅)
- **Language:** ZEP Script (JavaScript)
- **CI/CD:** GitHub Actions (ESLint 코드 컨벤션 자동 검사)

## 📂 디렉토리 구조

```text
├── .github/workflows/    # CI/CD 파이프라인 설정
├── scripts/              # ZEP 스크립트 메인 폴더
│   ├── main.js           # 앱 진입점 및 전역 상태 관리
│   ├── modules/          # 기능별 모듈화 스크립트
│   │   ├── quiz.js       # 퀴즈 및 방탈출 로직
│   │   ├── password.js   # 비밀번호 문 잠금 해제 로직
│   │   └── reward.js     # 보상 및 팝업창 연동 로직
│   └── utils/            # 공통 유틸리티 함수
├── data/                 # 퀘스트 및 NPC 대화 데이터 (JSON)
├── assets/               # 그래픽 및 사운드 에셋 백업
└── README.md             # 프로젝트 개요 및 가이드
```

## 👥 팀 구성 및 역할

- **기획 & UI/UX 팀:** 메인 시나리오, 퀘스트 스토리보드 작성, 동선 설계
- **그래픽 디자인 팀:** 맵 타일셋, 아바타 스킨, 오브젝트 도트 리소스 제작
- **개발 & 스크립트 팀:** ZEP 에디터 맵 레이아웃 구축, 상호작용 스크립트 로직 구현
- **사운드 & BGM 팀:** 배경음악 및 상호작용 효과음 세팅

## 🌿 브랜치 전략 (Branch Strategy)

안정적인 배포와 병렬 테스트를 위해 다음과 같은 브랜치 전략을 사용합니다.

- `main`: 실제 ZEP 스페이스에 배포되는 안정화 버전
- `dev`: 개발팀 내부 테스트용 통합 브랜치
- `feature/{기능명}`: 개별 기능 개발 브랜치 (예: `feature/quiz-logic`, `feature/door-lock`)
    - 기능 개발 완료 후 `dev` 브랜치로 Pull Request (PR) 생성

## 💬 커밋 컨벤션 (Commit Convention)

원활한 이력 관리를 위해 커밋 메시지는 아래 규칙을 따릅니다.

- `feat`: 새로운 기능 추가 (예: `feat: NPC 대화 팝업 스크립트 추가`)
- `fix`: 버그 수정
- `docs`: 문서 수정 (README.md 등)
- `style`: 코드 포맷팅, 세미콜론 누락 수정 등 비즈니스 로직에 영향이 없는 변경
- `refactor`: 코드 리팩토링
- `chore`: 빌드 업무, 패키지 매니저 설정 등
